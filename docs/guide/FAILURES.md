# FAILURES — the mistake classes we have paid for, and the guard standing on each

Organized by CLASS, not by date — the same mistake in new clothes must be
recognizable. Each: the class · the instance that taught it · the guard now
standing · what reopening it would look like.

## Absence rendered as a value

- **Instances**: NAV drawdown register returning due_for_review: [] over an
  unevaluable trigger; `len(None or []) == 0` printing "nothing to ask";
  `x or 0` turning unread into zero; a 422 refusal printed as `None`
  (the chair's own hand, 2026-08-26); P2 "unchecked" while substantively
  satisfied (Grace, 2026-08-27).
- **Guard**: absence discipline in every seat brief; `unevaluable_reason`
  vocabulary; "make the unreadable case an INPUT, not a patch" (builder
  EVOLVE, ENG1). The class keeps recurring — treat every new payload field
  as suspect until its null path is read.

## The unwired kill switch (a control that exists and nothing calls)

- **Instances**: RiskMonitor with zero callers; the snapshot built and never
  scheduled; a green test class over an uncalled guard (HW3); the census
  test's own carve-outs.
- **Guard**: "a control is not done until something calls it — wire it to a
  clock or say plainly it is unwired." Every new control names its caller.

## The phantom (a fabricated or stale number entering the record)

- **Instances**: the phantom price factor (~44%/yr); the phantom GLD fill;
  P1 reading `met` on a test-artifact exit fired on a fabricated mark
  (found 2026-08-27, fence pending Friday's real evidence).
- **Guard**: the CLEAN FIELD RULE (fix the cause, re-baseline beside the
  preserved value, measured magnitude, human decision); mark-sanity
  corroboration on orders.

## Integrity is not completeness

- **Instance**: 1,611/1,611 events hash-chained AND a 42.6-hour hole where
  Tuesday 2026-08-25 simply is not recorded — provably unedited, unprovably
  complete (Grace's retraction, 2026-08-27).
- **Guard**: the host watchdog (cause); the NAV-strike gap alarm (detection,
  open). Doctrine: completeness is an adversarial control because the null
  and healthy readings are byte-identical, and mutual agreement between
  stale folds reads as corroboration.

## The stale-base / moving-target dispatch

- **Instances**: two builders independently building the same three doors
  (~350 duplicated lines); hw4 frozen on a base that predated a security
  fix; ENG2's brief carrying a base one commit older than a fact the brief
  itself asserted.
- **Guard**: a stacked dispatch names a FROZEN SHA; the chair re-checks the
  base at fire time; the builder checks the brief's facts are IN the base.

## The paper trail that outruns execution

- **Instances**: one rec decided EIGHT times with execution never recorded;
  11 of 20 "open" recommendations already executed; "deferred past Monday"
  firing into silence (instance 4 of the written-trigger class).
- **Guard**: the redecision guard (decided-and-re-presented-bare is a 409
  with lineage); execution evidence as ticket stage six, rendered loudest;
  deferral dates as ticket fields the queue read evaluates.

## The two-truths rendering (one rule, N derivations)

- **Instances**: the CEO's page and the spine disagreeing by eleven rows;
  169-vs-187 (two true partitions read as a dispute); the desk counter not
  consulting the router it published (routing v2, the chair's own commit).
- **Guard**: one named function per rule, every surface consumes it; the
  reconciliation tests that assert cross-instrument agreement by leg.

## Trusting the instrument's reading over the instrument

- **Instances**: the merge gate's "0 sensitive" on a diff deleting a guard;
  a probe calling the old signature and "confirming" the old number; the
  harness around a benchmark invalidating it silently.
- **Guard**: verify the instrument before believing its reading; the
  adversary calls the real layer, never the author's model of it.
