**Author: cdo-trial (audition dispatch, 2026-08-20). Filed verbatim by the
CTO at resolve; CTO note at the bottom. Evidence: 33 headless-Chrome
captures (21 individually inspected) in the session scratchpad `cdo/`

## Deliverable A.1 — the design language, versioned (v1)

**Type scale (5 steps).** `hero` 4xl mono light tabular (money only) →
`numberLg` 2xl → `title`/`body` 14px → chips 11px → `label` 10px mono
uppercase tracking-0.18em. Every number mono tabular; every section label
small-caps mono. Two heading grammars coexist and are now stated as a RULE:
**cockpit surfaces (Monitor, Allocate, Risk) label sections in mono caps;
office surfaces (Desk, seat pages) speak in sentences.** Machines get
labels; rooms get sentences.

**Space.** Cards `rounded-2xl p-5`, gap-4, thin borders; hierarchy from type
and whitespace, never colour weight. System defect: `KT.container` declares
`max-w-[1200px]` as THE token but every audited page hand-rolls
`max-w-[1600px]` — the token is dead and the real system is undocumented
(`theme.ts:78`). Version the real value or delete the token.

**Colour (three registers + two semantic hues).** Text carries provenance:
measured `--kt-text-strong`, asserted `--kt-text-dim`, apparatus
`--kt-text-muted` — surviving the light flip as a rebuilt relationship, not
an inversion (verified). Emerald = the fund (versioned 2026-08-15: survives
ONLY on signed P&L); violet = the machine's sentences; up/down/warn are the
only other chroma. Faces stroke `currentColor`. **Theme reality measured:**
the Studio has exactly two states — `data-kt-theme` is always stamped (the
no-flash script stamps dark even in its catch branch, `ThemeToggle.tsx:51-59`);
`prefers-color-scheme` is never consulted, so an OS-light first-time visitor
gets dark. Defensible for a dark-reference cockpit but currently an
ACCIDENT — record it as a versioned decision or honor the OS on first visit.

**Motion.** Exactly one informational animation: `kt-breathe` (4s, floor
0.45, working-seat dot only; reduced-motion removes motion, keeps the marker
drawn — `studio-theme.css:117-145`). Loading spinners are the only other
motion and ignore the media query (Tailwind default) — acceptable for
"still loading" per web.dev's guidance, but calm them under `motion-safe`.
Nothing else moves. This restraint is the house style.

**The office grammar.** A *desk* is a seat with a face, a status dot, its
last delivery, and a door — never a metric panel. A *face* is assigned,
never generated; absent actor → dashed featureless head; humans round,
machines square. A *memo card* owes its reader: who asks, what kind, what
accepting does, and its undo-cost. The *wire* may show only interactions
that happened, actor-exact, newest first. Applied consistently on every
seat page inspected — the firm's best asset.

**Absence design — the house signature, largely ALREADY RIGHT.** Measured
zero ≠ absent; absence renders as a sentence naming what is unknown and why
it is not zero ("Factor map unavailable — 2 priced holdings; a factor map
needs at least 3"; "Risk monitor unreachable — cannot confirm limits are
being enforced"; flat-NAV annotated "telemetry, not the NAV record").
Dead-spine branches are tested and every error state names its source. A
valid finding: this system is right; the defects below are where surfaces
fall short of their own standard.

## Deliverable B — `/desk/floor`: the 2.5D lobby, specified

Fixed-camera dimetric room behind `NEXT_PUBLIC_STUDIO_FLOOR=1`; the 2D
pages remain the working truth; the floor is presence, traffic, state.

**Geometry = the org chart.** Back wall exec row: Neelesh's corner office
(the only desk with an inbox tray — the approval queue lives there and only
there), Vishesh beside it (triage tray feeding the corner office), Fable's
console (dispatch board). The bench in constitution order, two rows of
four. **The chain as corridor**: mechanism → adversary's table → the
console → the machine room (belt/gate as square-faced machines) → the
corner office; no shortcut aisle exists because none exists in the
constitution. The venue door with the auto-policy as a small CAGED
square-faced machine beside it — the cage is the envelope. Abhishek's wing:
a drawn door, "thesis — observe only", opening to his existing page.

**Live truth**: wire pulses only for real desk events (each carries
`data-event-id`; no ambient traffic ever); working seat = lamp lit +
`kt-breathe`; halt dims the room one step and lights a red strip on the
venue door with the sells-exit staying lit; dead spine = unlit floor,
RiskBar's own sentence, zero pulses/lamps/chips (unknown ≠ idle), every
desk still clickable. Click a desk → the existing `/desk/<seat>` page
(250ms zoom; instant under reduced motion).

**Tech: CSS 3D transforms + inline SVG, NO three.js.** three.js ≈ 155KB
gzip (cited: discourse.threejs.org bundle measurements, bundlephobia) vs
0KB for CSS transforms; ~12 desks and ≤20 pulses is far below WebGL's
break-even; DOM keeps the house's absence *sentences*, text selection, and
native screen-reader access; three.js would buy free cameras and lighting,
which the spec deliberately forbids. Buying capability the design refuses
is how bundles rot.

**Falsifiable acceptance criteria** (each with its falsifier): (1) decision
latency unharmed — approval reachable in ≤2 navigations + 1 click, floor
adds 0; (2) reduced motion — `document.getAnimations()` empty under the
media query, pulses replaced by dashed aisle + count chips with full
information parity; (3) dead spine — no lit lamp, pulse, or idle/working
chip; all links navigate; (4) every pulse carries a real event id — replay
test asserts pulse count == desk-event count; (5) keyboard/a11y — semantic
`<nav>`, Tab order = constitution order, accessible names from `faces.ts`
roles, no new axe violations; (6) bundle — zero new dependencies, route JS
delta <30KB gzip measured on the builder's worktree; (7) theme parity —
`--kt-*` tokens only, no hardcoded hex.

**What the floor deliberately does not show**: no numbers, no
recommendation text, no decidable control, no people walking, no sound, no
replay in v1, no thesis interior. Three questions only — who is in, what is
moving between whom, is the room dark — and everything else is a door.

## Appendix — observed, not prescribed (Thesis, Abhishek's surface)

Observations only: the page reads in a different register (saturated
emerald CTAs and score bars where the Studio reserves emerald for signed
P&L; promotional voice where the Studio is declarative; its own chip
styles) — and it does things the Studio could envy (states its latency
on-surface, counts its evidence). Recorded solely so the CTO can relay a
language-consistency conversation if Abhishek ever wants one.

## What was not checked

True dead-spine pixels (live spine untouched — branches reviewed from code
plus the builder's recorded 19-route pass); current bundle sizes (no build
artifact; `next build` corrupts a live dev server — reported absent);
hover/tooltip states (headless); six of eight bench-seat captures taken
but not individually inspected (template verified on pm and validator;
nothing cited rests on the six); light parity beyond 4 surfaces (inferred
from token architecture).
